# 🛠️ CPP_DSA_SOLVER

A comprehensive collection of Data Structures and Algorithms (DSA) problems solved efficiently using modern C++. This repository serves as a personal tracker for problem-solving milestones across platforms like LeetCode, GFG, and Codeforces.

## 📁 Repository Structure

- `📂 BASICS-01`: Basic patterns, basic math, and syntax implementation.
- `📂 ARRAYS`: Fundamental array manipulations, searching, and sorting solvers.
- `📂 SUBARRAY`: Specialized algorithms for sliding window, Kadane's algorithm, and prefix sums.

## 🛠️ How to Compile & Run
To run any of the solutions locally, use any standard C++ compiler:
```bash
g++ -std=c++17 filename.cpp -o solver && ./solver
```

## 📈 Tech Stack & Features
- **Language:** C++17 / C++20
- Optimized for time and space complexity with detailed dry-run comments inside the files.
